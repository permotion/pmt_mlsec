## Hypothesis

URL structure features give different context to `url_length` in the GET subpopulation. The 935 GET FPs from v3 have longer URLs than normal traffic, but no payload indicators. Path and query string structure should separate better than total length.

---

## Pre-analysis — GET subpopulation

Correlations calculated **exclusively on the 43,088 GET requests** (70.6% of dataset):

| Feature | GET correlation | Global correlation | Signal |
|---|---|---|---|
| `url_has_query` | **+0.341** | +0.175 | ✅ GET attacks have query string more frequently |
| `url_path_depth` | **-0.318** | -0.198 | ✅ Normal GET traffic has deeper paths |
| `url_query_length` | **+0.297** | +0.178 | ✅ GET attacks have longer queries |

All three features show significantly stronger correlation in the GET subpopulation than globally — confirms that subpopulation analysis is the right approach. Global correlation is diluted by GET+POST mixture.

---

## Evaluated features

| Feature | How it is calculated | Decision |
|---|---|---|
| `url_path_depth` | `count('/')` in the path (before `?`) | ✅ add |
| `url_query_length` | `len()` of the query string (after `?`) | ✅ add |
| `url_has_query` | `1` if the URL contains `?` | ✅ add |

## Analysis

**Largest Precision jump in the entire project:**
- XGBoost: 0.649 → 0.793 (+0.144) — largest improvement in a single iteration
- LightGBM: 0.713 → 0.803 (+0.090) — first time exceeding 0.80
- LightGBM remaining gap: **0.803 → 0.85 = 0.047**

**ROC-AUC ceiling broken for the first time:**
- The ~0.955 plateau held in v1/v2/v3 was broken: 0.955 → **0.966**
- URL structure features provided genuinely new information

**FPs dropped drastically:**
- LightGBM: 1444 → 877 (-567) — direct confirmation that GET FPs were the bottleneck
- XGBoost: 1946 → 933 (-1013) — over 50% reduction

**0.9492 Recall — threshold effect, not capacity:**
- RF, XGBoost and LightGBM show exactly 0.9492 — 0.0008 below criteria
- The threshold is optimized on val; test set gives a marginally different result
- 0.966 ROC-AUC confirms sufficient separation capacity — it's calibration, not missing information
