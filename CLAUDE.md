## What is this project

**PMT MLSec** is an attack detection system using Machine Learning.
MVP with two binary classification models:

| Model | Input | Dataset | Output |
|---|---|---|---|
| A — Web Attack Detection | HTTP request features | CSIC 2010 | normal / attack |
| B — Network Attack Detection | Network flow features | UNSW-NB15 | benign / malicious |

**Offline** detection in the MVP — no real-time blocking yet.

## Conventions

### Datasets in `data/raw/`
- Never modify files in `data/raw/` — they are the source of truth
- Each dataset has its subfolder with `README.md`, `LICENSE`, and SHA-256 hash
- Processing always reads from `raw/` and writes to `processed/`

### Labels
- `0` = benign / normal
- `1` = malicious / attack
- Consistent in both models

### MVP Target Metrics

| Model | Min Recall | Min Precision | Min F1 | Min ROC-AUC |
|---|---|---|---|---|
| A — CSIC 2010 | 0.95 | 0.85 | — | — |
| B — UNSW-NB15 | — | — | 0.88 | 0.95 |

### Notebooks
- Used **only** for EDA and exploration
- Never call notebooks from Airflow DAGs
- When a notebook matures → `/refactor-notebook` converts it to script

### MLflow
- Each experiment: one run with logged parameters, metrics, and artifacts
- Naming: `mlsec-model-a-{description}` / `mlsec-model-b-{description}`
- See `docs/mlflow.md` for full naming conventions

### Airflow DAGs
- One DAG per model: `dag_model_a.py`, `dag_model_b.py`
- Minimum tasks: `ingest → preprocess → train → evaluate → register`
- See `docs/roadmap.md` for when to introduce Airflow
